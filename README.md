# Lancell

Site institucional da Lancell Assistência Técnica de Celulares, Vila Haro, Sorocaba. HTML, CSS e JavaScript, sem dependências.

`npm run dev` inicia a prévia em http://localhost:3000. `npm run check` verifica o JavaScript. `npm run build` gera o site estático em `dist/`.

Na Vercel, use o preset Other, comando de build `npm run build` e diretório de saída `dist`.

Atendimento guiado monta uma mensagem localmente e abre o WhatsApp; não armazena dados. Avaliações e horários consultados no perfil do Google Maps em 19/11/2026. Confirmar disponibilidade dos reparos e marcas com a loja; o site não promete prazos ou condições de garantia. Imagens ilustrativas de aparelhos e reparos reaproveitadas do projeto Império das Telas conforme referência solicitada; não representam trabalhos realizados pela Lancell. Identificação do cabeçalho composta tipograficamente, sem reprodução do logotipo original.
